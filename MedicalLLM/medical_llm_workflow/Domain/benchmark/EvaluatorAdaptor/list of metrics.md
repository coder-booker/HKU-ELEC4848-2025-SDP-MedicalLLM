Q&A
Accuracy (准确率): 所有预测正确的样本占总样本的比例 。

Precision (精确率): 预测为阳性的样本中，真正为阳性的比例 。

Recall (召回率): 真实为阳性的样本中，被正确预测为阳性的比例 。

F1: 精确率和召回率的调和平均数 。

AUC / AUPR: 接收者操作特征曲线（ROC）和精确率-召回率曲线下的面积，反映模型在不同阈值下的综合分类能力 。

Top-k 系列 (Accuracy/Precision/Recall): 评估模型的“前 $k$ 个输出”中是否包含真实标签，用于多疾病鉴别诊断（DDx）场景 。


短答/推理过程
Correctness (正确性): 响应在医学专业知识层面是否正确 。

Consistency (一致性): 回复的内容与Ground-truth输入信息是否保持一致，无自相矛盾 。

Clarity (清晰度) / Satisfaction (满意度): 文本表述是否清晰易懂，以及整体回复是否令人满意 。

Professionality (专业性): 模型引用的证据是否符合垂直领域的医学常识和临床指南 。

Completeness (完整性): 回复是否充分涵盖了诊断所需的所有重要方面 。

Hallucination (幻觉): 响应中是否包含了与前文语境不一致，或凭空捏造的医学信息 。

Relevance (相关性): 回复的内容是否与用户提问的语境紧密相关 。

Coherence (连贯性): 评估与对话历史的逻辑连贯性（上下文衔接是否合理） 。
